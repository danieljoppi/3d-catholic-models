# Statues

Standalone devotional figures — saints, the Sacred Heart, Our Lady under her
various titles, crucifixes.

Nothing here yet. When the first images arrive, create a set:

```
collections/statues/<set-name>/
  metadata.json
  README.md
  _inbox/
  pieces/<NN-slug>/{piece.md,reference/,model/{source,export},renders/}
```

Sets group figures that belong together — one artist, one style, one
commission. A single figure with no series of its own can live in
`collections/statues/singles/`.

See `docs/folder-structure.md` and `docs/naming-conventions.md`.
