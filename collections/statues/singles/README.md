## Rights

This set can mix origins in a way a single-origin series cannot, so record the
provenance **per piece**: a reference photographed from an existing carving
carries the sculptor's rights, a generated one does not. The set's
`metadata.json` has a `rights` block for the defaults; note per-piece exceptions
in the piece's own `piece.md`.
